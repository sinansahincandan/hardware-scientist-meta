---
name: vibratory-draft-reduction-sizing
description: Use when sizing any vibrating soil-cutting blade to keep draft below wheeled traction.
source: run 20261103-105032_lunar-regolith-excavation-robot (2026-11-03)
---

1. Estimate static shallow-cut draft for target depth, width and BP-1 simulant (cohesion 0-2.0 kPa) - e.g. 129 N static cut (E7).
2. Apply vibratory reduction factor for eccentric / shaking share - e.g. 129 N -> 90.3 N ~30% reduction (E32).
3. Estimate available wheeled traction on loose soil from total weight and grip - e.g. 222 N traction (E33) vs 650 N total weight (E48).
4. Check: vibrated draft < traction with margin >2x before fixing depth/skids; if not, reduce depth or add vibration power (~30 W vibrator) (E35, E39).
