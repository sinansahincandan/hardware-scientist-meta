---
name: steep-hopper-dump-sizing
description: Use when sizing any steep-wall carry hopper for cohesive bulk solid gravity discharge.
source: run 20261102-214939_lunar-regolith-excavation-robot (2026-11-02)
---

1. Get bulk density and angle of repose (e.g., 1.5 g/cc [E2,E3], repose ~45 deg [E13,E14]).
2. Set hopper wall steeper than repose +10-15 deg for mass flow (e.g., 60 deg steep wall). 
3. Size volume for target payload mass: m = volume*density (e.g., 20 L = 30 kg [E18]).
4. Provide tip angle exceeding wall friction for clean gravity dump (e.g., tip 45 deg rear via pivot and chute).
5. Check carry without spill during driving and dump into bin without bridging.
