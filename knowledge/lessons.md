# Lessons (light copy — the full record with sources and use notes is lessons_full.md)


## Process
- L29: Council consensus should separate exterior-form commitments from interior-sequence commitments for section views so verification judges overall shape adaptation separately from internal order.
- L25: Council consensus should record operating directionality (leading vs trailing end) together with parts presence so verification judges front-rear placement consistently. (used 2×, helped 2×)
- L22: Council consensus should record rotating-to-static clearance commitments with joint aero-structures-safety ownership so verification judges operable separation, not just part coexistence.
- L23: Council consensus should record power-path continuity from generation to load as an ordered chain so verification judges end-to-end connectivity over isolated parts. (used 1×, helped 1×)
- L21: Council consensus should explicitly authorize visibility-driven proportion exaggerations for small or occluded features so verification judges communicative intent over literal geometry.
- L19: Council consensus should record expected visible-instance counts from the agreed viewpoint alongside total membership for symmetric assemblies, so verification distinguishes occlusion from omission.
- L18: Council consensus should record quantitative along-axis station positions for stacked assemblies, not only part order, so internal and external depictions share the same placement ground truth.
- L16: Council consensus should explicitly record the host-system mounting interface alongside internal assembly order so verification judges integration completeness, not isolated device shape. (used 1×, helped 1×)
- L17: Council deliberation should require adjacent-domain owners to jointly confirm soft-to-rigid transition compatibility before agreement so layer sequence is buildable as well as depictable. (used 1×, helped 1×)
- L15: Council consensus should explicitly confirm viewpoint-specific layout order of major assemblies, not only parts presence, so downstream checks judge agreed structure over isolated components. (used 9×, helped 8×)
- L14: Council consensus should record which capacity or quantity depictions may be representative rather than literal so visual verification judges structural intent over exact counts. (used 13×, helped 13×)
- L11: Manager should require meeting consensus to record joint structural commitments with explicit owner per commitment so downstream accountability stays clear.
- L1: When the Manager revises Meeting protocol and Criteria, it must also align Roles so decision ownership stays consistent with the new process and standards. (used 2×, helped 2×)
- L2: Meeting protocol should require each member to articulate domain-specific constraints and cross-domain tradeoffs explicitly before agreement, so consensus integrates distinct expertise. (used 14×, helped 14×)
- L3: When a meeting closes by cap and the evaluator rejects, require the manager edit to target Roles and Meeting protocol in addition to Criteria to restore consensus close in the next iteration. (used 2×, helped 2×)
- L4: When meetings repeatedly close by cap and evaluator rejects, require manager to make a converging edit or scope cut rather than no-op carryover to next iter. (used 1×, helped 1×)
- L5: Require cited evidence ids before any ready vote in the meeting protocol.

## Prompts
- L30: Manager image briefs should specify cross-section cut treatment with retained exterior envelope alongside viewpoint so generation preserves interior order within recognizable overall form.
- L28: Manager image briefs should state functional transfer alignment in viewpoint-relative terms alongside parts enumeration so generation preserves agreed sender-to-receiver connectivity.
- L27: Manager image briefs should state intended operating pose explicitly alongside viewpoint so generation preserves agreed articulation rather than defaulting to neutral stowed shape.
- L26: Manager image briefs should include an overall length anchor alongside viewpoint and setting so generation preserves long-low proportions of ground-working assemblies.
- L24: Manager image briefs should use neutral engineering vocabulary for small-scale energy devices to avoid content-filter triggers while preserving agreed structure.
- L20: Manager image briefs should translate council-agreed assembly order into viewpoint-relative zone language so generation preserves agreed placement in the chosen view.
- L12: Master prompts should state intended viewpoint and operational setting alongside parts so council agreement and visual verification share the same framing. (used 12×, helped 12×)
- L6: Master prompts should specify connection topology between parts, not just a parts list, so council deliberation and visual verification share the same structural ground truth. (used 12×, helped 11×)
- L7: Council rosters should define complementary specialties with explicit ownership areas so deliberation covers all domains without overlap or gaps. (used 16×, helped 15×)

## Tools
- L8: Require manager edits to tie directly to evaluator rejection reason with converging scope; expanding edited sections without convergence does not resolve cap-reject loops.

## Image model
- L13: Manager image briefs should specify intended support and mounting treatment for ground-standing assemblies so rendering does not invent extra foundations or merge distinct structures.
- L9: Visual faithfulness judgments should prioritize presence, placement, and connectivity of major structures over exact counts of repeated elements, which generative rendering approximates imprecisely. (used 15×, helped 15×)
- L10: Image prompts for multi-part products should enumerate all major structures and their visible connections from the chosen viewpoint to achieve faithful rendering. (used 11×, helped 11×)
