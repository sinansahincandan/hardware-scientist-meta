# Lessons (light copy — the full record with sources and use notes is lessons_full.md)


## Process
- L38: Council consensus should record vertical stratification commitments (low vs elevated placement) alongside horizontal layout so verification judges height order consistently in three-quarter views.
- L36: Council consensus should separate visually-verifiable depiction commitments from non-visual specification commitments so verification judges only what rendering can depict.
- L37: Council consensus should record articulation state of movable supports with viewpoint-visible cues distinct from parts presence so verification distinguishes deployed intent from omission.
- L35: Council consensus should enumerate agreed inter-layer boundaries as countable functional interfaces separate from parts presence so verification distinguishes true omission from rendering blend.
- L33: Council consensus should separate rendering-style appearance commitments from topology commitments so verification judges same-parts-same-connections as faithful across photorealistic vs diagram gap. (used 3×, helped 2×)
- L31: Council consensus should record agreed rotation handedness relative to the agreed viewpoint together with parts presence so verification judges spin direction consistently.
- L32: When council agrees on an unconventional arrangement, consensus should explicitly name the familiar archetype it rejects so downstream depiction does not revert to the conventional default.
- L29: Council consensus should separate exterior-form commitments from interior-sequence commitments for section views so verification judges overall shape adaptation separately from internal order. (used 1×, helped 1×)
- L25: Council consensus should record operating directionality (leading vs trailing end) together with parts presence so verification judges front-rear placement consistently. (used 5×, helped 5×)
- L22: Council consensus should record rotating-to-static clearance commitments with joint aero-structures-safety ownership so verification judges operable separation, not just part coexistence.
- L23: Council consensus should record power-path continuity from generation to load as an ordered chain so verification judges end-to-end connectivity over isolated parts. (used 4×, helped 4×)
- L21: Council consensus should explicitly authorize visibility-driven proportion exaggerations for small or occluded features so verification judges communicative intent over literal geometry.
- L19: Council consensus should record expected visible-instance counts from the agreed viewpoint alongside total membership for symmetric assemblies, so verification distinguishes occlusion from omission. (used 1×, helped 1×)
- L18: Council consensus should record quantitative along-axis station positions for stacked assemblies, not only part order, so internal and external depictions share the same placement ground truth.
- L16: Council consensus should explicitly record the host-system mounting interface alongside internal assembly order so verification judges integration completeness, not isolated device shape. (used 1×, helped 1×)
- L17: Council deliberation should require adjacent-domain owners to jointly confirm soft-to-rigid transition compatibility before agreement so layer sequence is buildable as well as depictable. (used 1×, helped 1×)
- L15: Council consensus should explicitly confirm viewpoint-specific layout order of major assemblies, not only parts presence, so downstream checks judge agreed structure over isolated components. (used 14×, helped 13×)
- L14: Council consensus should record which capacity or quantity depictions may be representative rather than literal so visual verification judges structural intent over exact counts. (used 19×, helped 19×)
- L11: Manager should require meeting consensus to record joint structural commitments with explicit owner per commitment so downstream accountability stays clear.
- L1: When the Manager revises Meeting protocol and Criteria, it must also align Roles so decision ownership stays consistent with the new process and standards. (used 3×, helped 3×)
- L2: Meeting protocol should require each member to articulate domain-specific constraints and cross-domain tradeoffs explicitly before agreement, so consensus integrates distinct expertise. (used 19×, helped 19×)
- L3: When a meeting closes by cap and the evaluator rejects, require the manager edit to target Roles and Meeting protocol in addition to Criteria to restore consensus close in the next iteration. (used 2×, helped 2×)
- L4: When meetings repeatedly close by cap and evaluator rejects, require manager to make a converging edit or scope cut rather than no-op carryover to next iter. (used 1×, helped 1×)
- L5: Require cited evidence ids before any ready vote in the meeting protocol.

## Prompts
- L34: Manager image briefs should carry the council-agreed end-to-end connection chain verbatim into photorealistic briefs so generation preserves agreed order despite style shift. (used 1×, helped 1×)
- L30: Manager image briefs should specify cross-section cut treatment with retained exterior envelope alongside viewpoint so generation preserves interior order within recognizable overall form. (used 1×, helped 1×)
- L28: Manager image briefs should state functional transfer alignment in viewpoint-relative terms alongside parts enumeration so generation preserves agreed sender-to-receiver connectivity. (used 1×, helped 1×)
- L27: Manager image briefs should state intended operating pose explicitly alongside viewpoint so generation preserves agreed articulation rather than defaulting to neutral stowed shape.
- L26: Manager image briefs should include an overall length anchor alongside viewpoint and setting so generation preserves long-low proportions of ground-working assemblies.
- L24: Manager image briefs should use neutral engineering vocabulary for small-scale energy devices to avoid content-filter triggers while preserving agreed structure. (used 2×, helped 0×)
- L20: Manager image briefs should translate council-agreed assembly order into viewpoint-relative zone language so generation preserves agreed placement in the chosen view.
- L12: Master prompts should state intended viewpoint and operational setting alongside parts so council agreement and visual verification share the same framing. (used 18×, helped 18×)
- L6: Master prompts should specify connection topology between parts, not just a parts list, so council deliberation and visual verification share the same structural ground truth. (used 18×, helped 17×)
- L7: Council rosters should define complementary specialties with explicit ownership areas so deliberation covers all domains without overlap or gaps. (used 22×, helped 21×)

## Tools
- L8: Require manager edits to tie directly to evaluator rejection reason with converging scope; expanding edited sections without convergence does not resolve cap-reject loops.

## Image model
- L13: Manager image briefs should specify intended support and mounting treatment for ground-standing assemblies so rendering does not invent extra foundations or merge distinct structures.
- L9: Visual faithfulness judgments should prioritize presence, placement, and connectivity of major structures over exact counts of repeated elements, which generative rendering approximates imprecisely. (used 21×, helped 21×)
- L10: Image prompts for multi-part products should enumerate all major structures and their visible connections from the chosen viewpoint to achieve faithful rendering. (used 17×, helped 17×)
