## Objections
- O1 (resolved) Descent hold exceeds comfortable one-person sustained grip: 188 N hold needs auto-lock with no back-drive, release force must stay low enough to squeeze all flight without fatigue.
## Chief designer's selections
- F1 -> C22: Support needs a bending load path to axle. The twin-tube backbone (C22) is better because it is the only working means carrying the toe root moment 88.3 N m (E68) at 51.1 MPa (E70) vs 276 MPa yield; the step envelope (C4) and van envelope (C14) are same as necessary limits but do no supporting, and ergonomic cap note (C9) is worse as it states no means.
- F2 -> C23: Restrain needs preload to backrest. The webbing strap (C23) is better because it is the only working means preventing shift and shock doubling; the visibility rule (C10) is same as needed sightline limit but does no restraining, and empty fields (C5, C18) are worse as they offer no means.
- F3 -> C2: Flat motion needs rolling. The paired small wheels rolling as fixed cart (C2) is better because it is the only working rolling means giving 24.0 N push (E23); the loop grips (C8) are same as needed push interface but do no rolling, and empty fields (C16, C25) are worse as they offer no means.
- F4 -> C1: Stair traverse needs step walking. The tri-star cluster (C1) is better because it is the only working means pivoting over the 197 mm riser with 185 mm radius and 39.0 N m per side (E23) costing 116 J per riser (E22); pull posture (C11) is same as needed operating method but does no stepping, fold-down handle note (C19) is worse as it only aids stow, and empty fields (C6, C15, C26) offer no means.
- F5 -> C7: Limiting needs auto-lock with no back-drive. The dead-man lever with disc plus tooth park pin (C7 combined with C20 and C3 detail) is better because release means locked holding 67.0 N m (E51) against 209 N pull and 188 N hold (E23) exceeding 130-140 N sustained limits; friction-only contact brake (C3) alone is worse as it cannot be trusted without positive lock, and empty fields (C17, C27) offer no means.
- F6 -> C13: Collapse still needs telescoping handle plus folding toe-plate (C13) for 730 by 380 by 190 mm stow, now with clip-on transverse brace (C28) that pins across twin tubes when deployed and unclips alongside for fold, because braced deflection 13.8 mm versus 0.11 m whip keeps backbone one piece with joint count at toe plus handle plus one removable brace.
